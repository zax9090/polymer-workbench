# Rust 계산 커널과 구조·궤적 분석

Materials Studio의 기능 몇 가지를 공개 문헌의 정의대로 Rust로 새로 만들고 있습니다(`native/`, 파이썬 모듈 `workbench_native`). Materials Studio 파일이나 바이너리는 쓰지 않습니다. 각 커널은 정답이 알려진 경우나 독립 구현(MDAnalysis, LAMMPS)과 비교해 검증합니다.

## 상태

| 커널 | Materials Studio 대응 기능 | 상태 |
|---|---|---|
| `contacts` | Blends: 접촉 에너지 분포·배위수 → χ(T) | 완료. UI·API·MCP 연결, 실험적 기능([분자 접촉 χ](BLENDS.md)) |
| `trajectory` | Forcite Analysis: RDF g(r), MSD·확산 계수 | 작업 화면·API·MCP 연결. 정상 확산 구간을 확인하지 못하면 D는 `null` |
| `volume` | Atom Volumes & Surfaces: 점유·접근 가능·탐침 점유 부피, Bondi FFV | 작업 화면·API·MCP 연결. 거리장 가속과 h·2h 차이 보고. 탐침 점유 부피의 수렴은 여전히 별도 확인 필요 |
| `widom` | Sorption(헨리 영역): Widom 삽입 μ_ex·용해도 계수 | 작업 화면·API·MCP 연결. 단일 점 LJ 근사이며 실험값 예측의 한계 유지 |
| (계획) | Amorphous Cell | 파이썬 자체 빌더(`workbench/amorphous.py`)를 Rust로 옮기고 trans/gauche 통계를 넣을 예정 |

## 공통 구조

- `cells.rs`
  - 직교 주기 상자의 셀 리스트와 최소 이미지 규약을 처리합니다.
  - 차단 거리는 상자 길이의 절반 이하여야 하며, 파이썬 쪽에서 검사합니다.
- `rng.rs`
  - 샘플마다 (시드, 번호)로 xoshiro256** 난수열을 만듭니다.
  - rayon 병렬 계산에서도 스레드 수와 관계없이 같은 결과가 나옵니다.
- `python.rs`
  - PyO3 0.29.2 / numpy 0.29.0 바인딩입니다.
  - 입력 배열의 모양, 유한값, 인덱스 범위를 검사합니다.
- `setup.sh`는 `cargo`가 있으면 `pip install ./native`로 커널을 빌드합니다. CI는 Rust 단위 테스트를 돌린 뒤 커널을 빌드합니다. Rust 소스를 수정한 뒤에는 `.venv/bin/python -m pip install ./native`로 다시 설치해야 합니다.

## 사용법

완료된 전원자 벌크·가교 작업의 개요에서 **구조·궤적 분석**을 엽니다. 분석 방법과 원소·프레임·격자·삽입 조건을 선택해 실행하면 그래프 또는 표, 경고와 입력 출처를 볼 수 있습니다. **분석 JSON 저장**에는 실제 매개변수, 입력 파일 SHA-256, 커널 버전·해시, 분석 코드 해시가 포함됩니다. 분석은 기존 작업 파일이나 manifest를 변경하지 않습니다. 화면의 결과는 세션에 보관되므로 필요한 결과는 JSON으로 저장하세요.

API는 `POST /api/jobs/{job_id}/analysis`입니다. 예를 들어 RDF 요청은 다음과 같습니다.

```json
{"analysis":"rdf","parameters":{"pairs":["C-C","C-H"],"r_max":5.0,"bins":100,"every":1,"max_frames":100}}
```

`analysis`는 `rdf`, `msd`, `free_volume`, `widom` 중 하나입니다. MCP에서는 `analyze_job_structure`에 `job_id`, `analysis`, `parameters`를 전달합니다. 입력 제약은 `/docs`와 MCP 도구 설명에서도 확인할 수 있습니다. 잘못된 입력은 422, 미완료 작업은 409, 커널 미설치는 503, 다른 구조 분석 진행 중에는 429로 응답합니다. 서버 한 개에서는 한 번에 구조 분석 하나를 실행하며 다른 API는 계속 응답합니다.

- **RDF:** 원소 쌍, `all-all`, `heavy-heavy`를 지원합니다. 최대 거리는 가장 짧은 상자 길이의 절반 이하여야 합니다. 자기 쌍은 항상 제외하며, 같은 분자 쌍 제외는 선택입니다.
- **MSD:** 일정 간격으로 기록된 4개 이상의 궤적 프레임이 필요합니다. 전체 셀 질량 중심 이동 제거가 기본입니다. 양의 피팅 기울기와 로그–로그 지수 0.9~1.1인 경우에만 D 추정값을 표시하며, 이 판정도 평형이나 수렴의 증명은 아닙니다.
- **자유 부피:** 기본적으로 최종 데이터 파일의 구조를 사용합니다. `spacing`은 0.05~1.0 Å, `probes`는 0~5 Å입니다. h와 2h 격자의 절대 차이와 실제 각 축 간격을 보고합니다. 차이는 오차 상한이나 수렴 판정이 아닙니다.
- **Widom:** GAFF2 12-6 LJ 셀에서만 지원합니다. NPT 프레임에서는 부피 가중 평균 `B = ⟨V exp(−U/RT)⟩/⟨V⟩`로 `μ_ex = −RT ln B`를 계산합니다. 부피가 일정하면 기존 평균과 같습니다. 전하·사중극자·고분자 이완을 제외한 단일 점 기체 모델입니다. 삽입 가중치가 모두 0이면 화학 퍼텐셜은 `null`이며 충분한 샘플링의 증거로 해석하면 안 됩니다. 표준 오차는 비율 추정량의 선형화(`SEM[(V/⟨V⟩)(factor−B)]`)이며 프레임 상관과 모델 오차를 포함하지 않습니다.

직교 주기 상자와 `atom_style full`만 지원합니다. 모든 분석 프레임의 원자 ID·타입 일치와 시간 순서를 검사합니다. 잘못된 열·기울어진 셀·링크된 입력·비유한 값은 거부합니다. 원자·프레임·격자·계산량 제한을 넘으면 프레임을 줄이거나 격자 간격을 넓혀야 합니다.

## 입력 파일 (`workbench/structure_analysis.py`)

- **GAFF2 벌크 셀**: 샘플링 궤적 `eq3.dump`와 최종 데이터 파일 `eq3_last.data`를 씁니다. 데이터 파일에서 Masses, Pair Coeffs(LJ ε·σ), Atoms(full 형식)를 읽습니다.
- **PCFF·가교 셀**: 궤적이 없고 `final.data`만 있습니다.
  - RDF와 자유 부피는 최종 구조 한 장으로 계산합니다.
  - MSD는 계산할 수 없습니다.
  - Widom은 PCFF가 9-6 LJ라 지원하지 않습니다.
- **원소**: 질량에서 판별하고, 반지름은 Bondi 반데르발스 반지름을 씁니다.

## 기존 실제 셀 검증 기록

아래 PS·아르곤 값은 이전 커널 개발 때의 검증 기록입니다. 이번 연결 작업에서 그 대규모 계산을 다시 실행하지 않았습니다. 특히 PS Widom 값은 NPT 부피 가중 평균을 적용하기 전 기록이며, 현재 구현의 재계산 결과로 해석하지 않습니다. 새 구현의 합성 회귀 검증은 아래 별도 절을 참고하세요.

### RDF와 MSD (MDAnalysis 2.11과 비교)

PS 10량체 × 8 셀(1,296원자), 101프레임에서 비교했습니다.
- **RDF**: C–C, C–H 모두 상대 차이 10⁻⁴ 이하입니다.
  - MDAnalysis InterRDF와 같은 정규화를 씁니다. 순서쌍을 세고, 자기 자신과의 쌍과 제외한 같은 분자 쌍은 분모에서도 뺍니다.
  - 남은 차이는 MDAnalysis의 단정밀도(float32) 좌표 때문에 구간 경계에서 생깁니다.
- **MSD**: 시간창 평균 방식이 EinsteinMSD(fft=False)와 8×10⁻⁸ Å² 안에서 같습니다.
- **속도**: RDF 두 쌍을 계산하는 데 Rust는 덤프 파싱을 포함해 2.4초, MDAnalysis는 3.0초와 9.8초였습니다.
- **확산 판정**: 로그–로그 기울기가 0.9보다 작으면, 확산 계수 대신 "아직 확산 구간이 아님" 경고를 냅니다. 이 셀은 125 ps 샘플링이라 기울기가 0.04였습니다.

### Widom 삽입 (LAMMPS 22 Jul 2025 `fix widom`과 비교)

- **조건**: 아르곤 LJ 유체(ρ* = 0.5, T* = 1.5, 원자 500개, 차단 10 Å, 꼬리 보정 없음), 200프레임
- **LAMMPS**: μ_ex = −0.4008 ± 0.0026 kcal/mol (삽입 4,000회/프레임)
- **Rust**: μ_ex = −0.3999 ± 0.0017 kcal/mol (삽입 20,000회/프레임). 오차 범위 안에서 같습니다.
- **프레임별 상관**: LAMMPS는 `f_wid` 값을 한 간격(500스텝) 늦게 출력합니다. 이를 맞추면 같은 구조에서 상관 0.49입니다. LAMMPS 쪽 삽입 잡음을 감안하면 예상 범위입니다.
- **닫힌 식 검증**(단위 테스트): LJ 에너지, 최소 이미지, 꼬리 보정 8π/3·Σε σ³[(σ/r_c)⁹/3 − (σ/r_c)³]/V

**PS 셀에서의 결과와 한계**
- **결과**(298 K, 21프레임, 2만 삽입/프레임): 용해도 계수 CO₂ 9.4 ± 2.0, CH₄ 2.9, N₂ 0.55 cm³(STP)/(cm³·atm)
- **비교**: 순서(CO₂ > CH₄ > N₂)는 실험과 같지만, 값은 유리상 PS에 대해 보고된 값보다 대략 한 자릿수 큽니다.
- **원인 후보**
  - 셀이 짧게 평형화되어 밀도가 0.985 g/cm³로 실험(1.05)보다 낮습니다.
  - 고분자 구조를 고정한 채로 삽입합니다.
  - 기체를 단일 점 LJ로 모델링했고, 전하와 사중극자를 넣지 않았습니다.
- **용해도 식**: 일정 부피에서는 S = (273.15 K/T)·⟨exp(−U/RT)⟩. 현재 NPT 분석은 위의 부피 가중 평균 B를 사용합니다.

### 자유 부피 (해석해와 비교)

**정확도 검증**
- 구 하나에서 점유 부피와 접근 가능 부피가 4/3πr³과 4/3π(r + 탐침)³에 0.2% 안에서 맞습니다.
- 볼록한 구 하나에서는 탐침 점유 부피가 비점유 부피와 같습니다.
- 맞닿은 두 구 사이의 틈은 탐침 점유 부피에서 빠집니다.
- 경계를 넘는 구의 부피도 같습니다.

**PS 셀(밀도 0.985)**
- 점유율 0.5765, 탐침 0 자유 부피 0.4235, Bondi FFV(1 − 1.3 V_w/V) 0.25입니다.
- 이 세 값은 격자 간격 0.5, 0.3, 0.25, 0.15 Å에서 소수 넷째 자리까지 같습니다.

**격자 수렴과 거리장 가속**
- 탐침 점유 부피는 격자를 촘촘히 할수록 커지며, 아직 수렴하지 않았습니다.
  - 탐침 1.0 Å: 0.127(0.5 Å) → 0.166(0.25–0.3 Å) → 0.191(0.15 Å)
  - 탐침 1.65 Å: 0.024 → 0.035 → 0.040
- 원인은 탐침 중심이 들어갈 수 있는 공간이 작은 주머니들로 흩어져 있어서, 거친 격자가 그 주머니를 덜 잡는 데 있습니다.
- 이제 간격 h와 2h에서 각각 계산한 점유율·접근 가능율·탐침 점유율의 절대 차이를 함께 보고합니다. 각 축의 실제 간격도 기록합니다. 두 격자의 차이는 오차 상한이 아니며 위 PS 셀의 수렴 문제를 해결했다고 주장하지 않습니다.
- 거리장 탐색을 주기 경계를 고려한 경계 상자 트리로 바꿨습니다. 각 노드의 상자까지 거리에서 최대 원자 반지름을 뺀 하한으로 가지를 제외하고, 필요한 원자의 표면 거리만 정확히 계산합니다. 기존 히스토그램 탐색 거리 제한이 희박하거나 비등방적인 셀에서 거리를 잘라내던 문제도 수정했습니다.
- 동일한 합성 셀(512원자·125,000격자점·Rayon 2스레드)의 거리장 비교에서 기존 셀 탐색 1.364초, 트리 0.0752초(약 18.1배), 최대 거리 차이 0을 확인했습니다. **거리장 단계만의 측정**이며 전체 분석 속도나 이전 417만 점 PS 셀에서 같은 배속을 보장하지 않습니다. 재현 명령은 아래와 같습니다.

```sh
RAYON_NUM_THREADS=2 cargo test --release --locked --no-default-features --manifest-path native/Cargo.toml -- --ignored --nocapture
```

- 탐침 공을 찍는 단계는 접근 가능 영역의 경계 점에서만 찍도록 바꿔서, 빈 공간이 넓은 경우에도 빠릅니다.

## 합성 회귀 검증 (2026-10-23)

Python 3.12.14·Rust 1.99.1 환경에서 실제 Python 확장을 빌드했습니다. 새 회귀 테스트는 사용자 연구 데이터 대신 합성 셀을 사용합니다.

- `tests/test_structure_analysis.py`: 42개 통과. MDAnalysis 2.11의 같은 자기 쌍 제외 조건(`InterRDF(..., exclusion_block=(1,1))`)에서 RDF 최대 상대 차이 0, `EinsteinMSD(fft=False)`와 최대 절대 차이 5.55×10⁻¹⁷ Å²였습니다. 이 값은 합성 fixture에 대한 결과이며 모든 궤적의 정확도 보증이 아닙니다.
- 8 Å 상자 내 탄소 구 하나·0.1 Å 격자에서 점유율의 해석해 대비 절대 차이 0.000180613, 반지름 1 Å 탐침의 접근 가능율 차이 0.000515708을 확인했습니다. 이는 **비율의 절대 차이**이며 상대 오차와 다릅니다.
- 상자 원점만 움직이는 정지 원자의 MSD가 0인지 확인했습니다. 언랩 좌표는 절대 위치 `x + image×L`을 사용하고 RDF용 좌표만 `x−lo`로 옮깁니다.
- NPT Widom 평균은 부피 1000·2000과 프레임 인자 1·3에서 7/3, 비율 추정량의 독립 프레임 표준 오차는 8/9입니다. 일정 부피에서는 단순 평균·표준 오차와 같습니다.
- `tests/test_native_bindings.py`: 56개 통과. 배열 모양·NaN/무한대·중복 인덱스·작은 차단 거리로 인한 셀 할당 폭증·계산량 초과를 검사합니다.
- `tests/test_structure_analysis_api.py`: 36개 통과. 네 분석의 실제 Rust 계산, 입력 파일 해시 보존, API/MCP, 경로 제한, 잘못된 요청, 분석 중 서버 응답을 확인합니다.
- Rust 기본 단위 테스트 13개 통과. 수동 성능 비교 1개는 일반 실행에서 제외하고 별도 실행했습니다.
- Chromium에서 네 분석을 실제 HTTP 서버로 요청해 결과 그래프·표와 JSON 다운로드를 확인했고 JavaScript 오류는 없었습니다. 별도 화면 검증에서 작업 전환 중 결과 혼동·오류 이스케이프·390 px 화면을 확인했습니다.

```sh
RAYON_NUM_THREADS=2 OPENBLAS_NUM_THREADS=1 .venv/bin/python -m pytest -q \
  tests/test_native_bindings.py tests/test_structure_analysis.py tests/test_structure_analysis_api.py
cargo test --release --locked --no-default-features --manifest-path native/Cargo.toml
```

## Rust 통계와 연구 흐름 확장 (2026-10-23)

`native/src/doe.rs`와 `statistics.rs`가 회귀 계수의 t 추론, ANOVA의 F 추론, 반복점의 순수 오차·적합 결여, 레버리지·표준화 잔차·Cook 거리·PRESS 예측 R², 평균 신뢰구간과 개별 관측 예측구간을 계산합니다. Python은 CSV·설정·저장을 담당하며 이 DOE 경로의 통계 추론에는 SciPy를 호출하지 않습니다. 같은 관측값의 모델 비교와 빈 확인 실험표가 API·MCP·화면 및 기존 벌크 연구 흐름에 함께 연결됩니다.

`tests/test_doe_statistics.py`는 독립 NumPy 최소제곱·공분산, 실제 행 제외 재적합, SciPy 분포와 대조하는 여섯 사례를 포함합니다. 정확 적합·일정 반응·추정 불가능한 모델은 따로 표시하며, 관측 행 삭제·모델 선택·다음 계산 실행을 자동으로 수행하지 않습니다. 개발 검사는 수치 구현을 확인하며 실험의 오차 가정이나 물리적 타당성을 보증하지 않습니다.

기존 `evidence/native/audit.json`은 그 안에 기록된 SHA-256 빌드의 정적 감사 기록입니다. 이후 통계 기능을 추가한 빌드까지 감사한 것으로 해석하지 않습니다.
