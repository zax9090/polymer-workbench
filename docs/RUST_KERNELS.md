# Rust 계산 커널 (진행 중)

Materials Studio의 기능 몇 가지를 공개 문헌의 정의대로 Rust로 새로 만들고 있습니다(`native/`, 파이썬 모듈 `workbench_native`). Materials Studio 파일이나 바이너리는 쓰지 않습니다. 각 커널은 정답이 알려진 경우나 독립 구현(MDAnalysis, LAMMPS)과 비교해 검증합니다.

## 상태

| 커널 | Materials Studio 대응 기능 | 상태 |
|---|---|---|
| `contacts` | Blends: 접촉 에너지 분포·배위수 → χ(T) | 완료. UI·API·MCP 연결, 실험적 기능([분자 접촉 χ](BLENDS.md)) |
| `trajectory` | Forcite Analysis: RDF g(r), MSD·확산 계수 | 커널과 파이썬 분석(`workbench/structure_analysis.py`) 완료. UI·API·MCP 연결 전 |
| `volume` | Atom Volumes & Surfaces: 점유·접근 가능·탐침 점유 부피, Bondi FFV | 커널 완료. 탐침 점유 부피의 격자 수렴 문제 남음. 연결 전 |
| `widom` | Sorption(헨리 영역): Widom 삽입 μ_ex·용해도 계수 | 커널 완료. LAMMPS와 일치. 연결 전 |
| (계획) | Amorphous Cell | 파이썬 자체 빌더(`workbench/amorphous.py`)를 Rust로 옮기고 trans/gauche 통계를 넣을 예정 |

## 공통 구조

- `cells.rs`
  - 직교 주기 상자의 셀 리스트와 최소 이미지 규약을 처리합니다.
  - 차단 거리는 상자 길이의 절반 이하여야 하며, 파이썬 쪽에서 검사합니다.
- `rng.rs`
  - 샘플마다 (시드, 번호)로 xoshiro256** 난수열을 만듭니다.
  - rayon 병렬 계산에서도 스레드 수와 관계없이 같은 결과가 나옵니다.
- `python.rs`
  - PyO3 0.29.2 / numpy 0.29.0 바인딩입니다.
  - 입력 배열의 모양, 유한값, 인덱스 범위를 검사합니다.
- `setup.sh`는 `cargo`가 있으면 `pip install ./native`로 커널을 빌드합니다. CI는 `cargo test`(현재 10개)를 돌린 뒤 커널을 빌드합니다.

## 입력 파일 (`workbench/structure_analysis.py`)

- **GAFF2 벌크 셀**: 샘플링 궤적 `eq3.dump`와 최종 데이터 파일 `eq3_last.data`를 씁니다. 데이터 파일에서 Masses, Pair Coeffs(LJ ε·σ), Atoms(full 형식)를 읽습니다.
- **PCFF·가교 셀**: 궤적이 없고 `final.data`만 있습니다.
  - RDF와 자유 부피는 최종 구조 한 장으로 계산합니다.
  - MSD는 계산할 수 없습니다.
  - Widom은 PCFF가 9-6 LJ라 지원하지 않습니다.
- **원소**: 질량에서 판별하고, 반지름은 Bondi 반데르발스 반지름을 씁니다.

## 검증 결과

### RDF와 MSD (MDAnalysis 2.11과 비교)

PS 10량체 × 8 셀(1,296원자), 101프레임에서 비교했습니다.
- **RDF**: C–C, C–H 모두 상대 차이 10⁻⁴ 이하입니다.
  - MDAnalysis InterRDF와 같은 정규화를 씁니다. 순서쌍을 세고, 자기 자신과의 쌍과 제외한 같은 분자 쌍은 분모에서도 뺍니다.
  - 남은 차이는 MDAnalysis의 단정밀도(float32) 좌표 때문에 구간 경계에서 생깁니다.
- **MSD**: 시간창 평균 방식이 EinsteinMSD(fft=False)와 8×10⁻⁸ Å² 안에서 같습니다.
- **속도**: RDF 두 쌍을 계산하는 데 Rust는 덤프 파싱을 포함해 2.4초, MDAnalysis는 3.0초와 9.8초였습니다.
- **확산 판정**: 로그–로그 기울기가 0.9보다 작으면, 확산 계수 대신 "아직 확산 구간이 아님" 경고를 냅니다. 이 셀은 125 ps 샘플링이라 기울기가 0.04였습니다.

### Widom 삽입 (LAMMPS 22 Jul 2025 `fix widom`과 비교)

- **조건**: 아르곤 LJ 유체(ρ* = 0.5, T* = 1.5, 원자 500개, 차단 10 Å, 꼬리 보정 없음), 200프레임
- **LAMMPS**: μ_ex = −0.4008 ± 0.0026 kcal/mol (삽입 4,000회/프레임)
- **Rust**: μ_ex = −0.3999 ± 0.0017 kcal/mol (삽입 20,000회/프레임). 오차 범위 안에서 같습니다.
- **프레임별 상관**: LAMMPS는 `f_wid` 값을 한 간격(500스텝) 늦게 출력합니다. 이를 맞추면 같은 구조에서 상관 0.49입니다. LAMMPS 쪽 삽입 잡음을 감안하면 예상 범위입니다.
- **닫힌 식 검증**(단위 테스트): LJ 에너지, 최소 이미지, 꼬리 보정 8π/3·Σε σ³[(σ/r_c)⁹/3 − (σ/r_c)³]/V

**PS 셀에서의 결과와 한계**
- **결과**(298 K, 21프레임, 2만 삽입/프레임): 용해도 계수 CO₂ 9.4 ± 2.0, CH₄ 2.9, N₂ 0.55 cm³(STP)/(cm³·atm)
- **비교**: 순서(CO₂ > CH₄ > N₂)는 실험과 같지만, 값은 유리상 PS에 대해 보고된 값보다 대략 한 자릿수 큽니다.
- **원인 후보**
  - 셀이 짧게 평형화되어 밀도가 0.985 g/cm³로 실험(1.05)보다 낮습니다.
  - 고분자 구조를 고정한 채로 삽입합니다.
  - 기체를 단일 점 LJ로 모델링했고, 전하와 사중극자를 넣지 않았습니다.
- **용해도 식**: S = (273.15 K/T)·⟨exp(−U/RT)⟩

### 자유 부피 (해석해와 비교)

**정확도 검증**
- 구 하나에서 점유 부피와 접근 가능 부피가 4/3πr³과 4/3π(r + 탐침)³에 0.2% 안에서 맞습니다.
- 볼록한 구 하나에서는 탐침 점유 부피가 비점유 부피와 같습니다.
- 맞닿은 두 구 사이의 틈은 탐침 점유 부피에서 빠집니다.
- 경계를 넘는 구의 부피도 같습니다.

**PS 셀(밀도 0.985)**
- 점유율 0.5765, 탐침 0 자유 부피 0.4235, Bondi FFV(1 − 1.3 V_w/V) 0.25입니다.
- 이 세 값은 격자 간격 0.5, 0.3, 0.25, 0.15 Å에서 소수 넷째 자리까지 같습니다.

**남은 문제**
- 탐침 점유 부피는 격자를 촘촘히 할수록 커지며, 아직 수렴하지 않았습니다.
  - 탐침 1.0 Å: 0.127(0.5 Å) → 0.166(0.25–0.3 Å) → 0.191(0.15 Å)
  - 탐침 1.65 Å: 0.024 → 0.035 → 0.040
- 원인은 탐침 중심이 들어갈 수 있는 공간이 작은 주머니들로 흩어져 있어서, 거친 격자가 그 주머니를 덜 잡는 데 있습니다.
- 다음 작업은 두 가지입니다.
  - 간격 h와 2h의 차이로 격자 오차를 함께 보고합니다.
  - 거리장 계산을 빠르게 합니다. 현재 0.15 Å 격자(417만 점)에서 약 2분 걸립니다.
- 탐침 공을 찍는 단계는 접근 가능 영역의 경계 점에서만 찍도록 바꿔서, 빈 공간이 넓은 경우에도 빠릅니다.
