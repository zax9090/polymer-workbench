# 공정 데이터 분석 검증 기록

`workbench/process.py`의 다섯 가지 분석(데이터 사전, 관리도, 공정 능력, 분산 성분, 층별 불량률 비교)을 해석해, 독립 구현, 시뮬레이션과 대조한 기록입니다. 사용법은 [사용설명서](MANUAL.md#공정-데이터-분석)에 있습니다.

## 구현 범위

| 분석 | 방법 | 범위 밖 |
|---|---|---|
| 관리도 | I-MR(σ = MR̄/d₂(2)), X̄–S(σ = s̄/c₄(n)), 3σ 한계, Western Electric 규칙 1–4와 6점 경향 | 크기가 다른 부분군, EWMA·CUSUM, 비정규 한계 |
| 공정 능력 | Cp·Cpk(단기 σ), Pp·Ppk(전체 표본 표준편차), 정규 가정 ppm, Ppk 95% 구간(Bissell 1990), Shapiro–Wilk | 비정규 공정 능력, 측정 시스템 분석(Gage R&R) |
| 분산 성분 | 균형 내포 확률효과 ANOVA, 기대 평균제곱(적률법), 바로 아래 단계로 F 검정 | 불균형 설계(REML), 분산 성분 신뢰구간 |
| 층별 비교 | 직접 표준화, Mantel–Haenszel 위험비·오즈비(Robins–Breslow–Greenland 구간), CMH 검정(연속성 보정 없음), Breslow–Day(Tarone 보정 없음) | 층 안의 다른 교란 요인, 위험비 신뢰구간 |

## 해석해와 표 값

- d₂(2) = 2/√π를 E|X₁ − X₂|의 수치 적분과 비교했습니다. 차이는 10⁻¹² 이하입니다.
- d₃(2) = √(2 − 4/π) = 0.8525, D₄(2) = 1 + 3d₃/d₂ = 3.2665입니다. 표준 표의 3.267과 같습니다.
- c₄(n)은 감마 함수 닫힌 식입니다. n = 2, 5, 10, 25에서 표 값 0.7979, 0.9400, 0.9727, 0.9896과 소수 넷째 자리까지 같습니다.

## 독립 구현과 대조 (statsmodels 0.14.5)

`scripts/crosscheck_process_statsmodels.py`는 무작위 입력 40개를 만들어 statsmodels와 비교합니다. statsmodels는 의존성이 아니므로 별도 가상환경에서 실행합니다. 2026-10-23 실행 결과는 다음과 같습니다(Python 3.13, NumPy 2.5.4, SciPy 1.18.1).

- **분산 성분 입력 범위**: 회차 3~24, 구역 2~5, 반복 2~3
  - 비교 대상: 내포 ANOVA 제곱합. statsmodels의 `ols("y ~ C(run) + C(run):C(zone)")`와 `anova_lm(typ=1)`을 썼습니다.
  - 결과: 최대 상대 차이 4.97×10⁻¹⁴입니다. 자유도는 모두 같았습니다.
- **층별 비교 입력 범위**: 층 2~5, 층마다 검사 20~500개
  - 비교 대상: `StratifiedTable`
  - 위험비·오즈비: 차이 0
  - 오즈비 95% 구간: 상대 차이 4.4×10⁻¹⁶
  - CMH 통계량: 상대 차이 1.9×10⁻¹⁴
  - Breslow–Day 통계량: 절대 차이 7.4×10⁻¹²

`tests/test_process.py`는 statsmodels 없이 NumPy 더미 변수 최소제곱으로 같은 제곱합을 다시 계산해 회귀 테스트로 확인합니다(상대 10⁻¹⁰).

## 시뮬레이션

- **분산 성분 편향**
  - 조건: 회차 21 × 구역 4 × 웨이퍼 2, 참값 300·200·100, 300회 반복
  - 평균제곱 평균: 2942.5·500.1·98.9. 기대값은 2900·500·100입니다. 회차 평균제곱의 몬테카를로 표준 오차는 약 ±53입니다.
  - 분산 성분 평균: 305.3·200.6·98.9
  - 음수 추정을 0으로 바꾸므로 성분 평균은 위로 약간 치우칩니다.
- **관리도 오경보율**: 정규 개별값 20만 점에서 규칙별 비율을 이론값과 비교했습니다.

  | 규칙 | 관측 | 이론 |
  |---|---|---|
  | 3σ 밖 1점 | 0.00271 | 0.0027 |
  | 2/3점 2σ 밖 | 0.0020 | 0.00205 |
  | 4/5점 1σ 밖 | 0.00451 | 0.00447 |
  | 6점 경향 | 0.00287 | 2/720 = 0.00278 |

  - 연속 8점 한쪽 규칙은 100만 점에서 0.00761이었습니다. 이론값은 2/256 = 0.00781이고, 시드 5개 평균 표준 오차는 약 0.00015입니다.
- **Ppk 95% 구간 포함률**: 정규 표본 2,000회를 돌렸습니다. n = 50에서 0.948, n = 200에서 0.960입니다. 몬테카를로 표준 오차는 0.005입니다.

## 강의 예제 재현

장비 A·B 예제(일반 A 18/900, B 1/100 · 고난도 A 12/100, B 90/900)에서 다음 값을 재현했습니다.
- 전체 불량률: A 3.0%, B 9.1%
- 표준화 불량률: A 7.0%, B 5.5%
- 두 층 모두에서 B가 낮은 방향 역전(심슨 역설)

B 대 A의 Mantel–Haenszel 위험비는 0.786, 오즈비는 0.765(95% 0.419~1.396)이고 CMH p는 0.392입니다. 이 예제는 강의용 수치이며 실측 자료가 아닙니다.

## NIST/SEMATECH Furnace 사례 (미실행, 사용자 PC에서 실행 필요)

- **대조 기준**: [핸드북](https://itl.nist.gov/div898/handbook/ppc/section4/ppc44.htm)에 공개된 내포 ANOVA 결과입니다.
  - 데이터: 산화막 두께, 21회 × 4구역 × 2웨이퍼 = 168개
  - 분산 성분: 회차 312.56, 회차 안 구역 225.38, 웨이퍼(잔차) 120.89
  - F비: 회차 5.37404, 구역 4.72864
- **공개 값의 일관성 확인**: 기대 평균제곱 식으로 MS_구역 = 120.89 + 2×225.38 = 571.65, MS_회차 = 571.65 + 8×312.56 = 3072.13이 됩니다. 그러면 F_구역 = 571.65/120.89 = 4.729, F_회차 = 3072.13/571.65 = 5.374로 공개 F비와 맞습니다.
- **미실행 이유**: 이 개발 환경에서는 NIST 서버에 접속할 수 없어 실제 데이터 대조를 아직 실행하지 못했습니다.
- **실행 방법**: 데이터 파일은 재배포 조건이 분명하지 않아 커밋하지 않습니다. NIST에 접속할 수 있는 PC에서 다음을 실행합니다.

```sh
.venv/bin/python scripts/validate_process_furnace.py
```

결과와 원본 파일의 SHA-256은 `evidence/process/furnace-validation.json`에 기록됩니다. 그 수치를 이 절에 옮기기 전까지 이 대조는 완료되지 않은 것으로 봅니다.
