# 분자 접촉 χ (Blends 방식, 실험적)

Materials Studio의 Blends 모듈이 쓰는 방법(Fan, Olafson, Blanco, Hsu, *Macromolecules* 25, 3667 (1992))을 공개 논문을 바탕으로 새로 구현했습니다. Materials Studio 파일은 쓰지 않았습니다. 계산이 무거운 부분은 Rust(`native/`, 파이썬 모듈 `workbench_native`)로, 나머지는 `workbench/blends.py`로 만들었습니다.

## 계산 방법

1. **성분 준비**
   - 각 성분은 단단한 분자 하나입니다. 용매나, `*`를 수소(또는 메틸)로 막은 고분자 반복단위입니다.
   - RDKit ETKDG와 MMFF로 3D 구조를 만들고, RadonPy GAFF2_mod로 LJ σ·ε와 Gasteiger 전하를 붙입니다.
2. **접촉 에너지(Rust)**: 네 쌍(기준–기준, 기준–상대, 상대–기준, 상대–상대) 각각에 대해 다음을 반복합니다.
   - 움직이는 분자를 균일한 무작위 회전과 무작위 방향으로 고정 분자에 다가가게 합니다.
   - Bondi 반지름 합(× `contact_scale`)에서 처음 닿는 거리를 원자쌍마다 2차방정식으로 정확히 구합니다.
   - 그 배치의 분자 간 LJ(Lorentz–Berthelot) + 쿨롱 에너지를 계산합니다. 차단 거리는 없습니다.
3. **배위수(Rust)**
   - 가운데 분자에 접촉한 분자를 하나씩 붙이되, 이미 붙인 분자와 겹치면 버립니다.
   - 연속 300번 실패하면 그 클러스터를 끝내고, 붙인 개수를 Z로 셉니다. 클러스터 평균을 씁니다.
4. **χ(T) 계산**
   - E_mix(T) = ½[Z_bs⟨E_bs⟩_T + Z_sb⟨E_sb⟩_T − Z_bb⟨E_bb⟩_T − Z_ss⟨E_ss⟩_T]
   - χ(T) = E_mix/RT
   - ⟨E⟩_T는 샘플한 접촉들의 볼츠만 평균입니다.
   - χ = A + B/T로 맞춘 뒤 Flory–Huggins 임계 χ_c = ½(n_b^−½ + n_s^−½)², 임계 온도(UCST/LCST), 스피노달을 구합니다.
5. **오차와 재현성**
   - 부트스트랩(에너지와 배위수 재표본)으로 기준 온도의 χ 오차를 냅니다.
   - 샘플마다 (시드, 번호)로 난수를 만들므로 스레드 수와 관계없이 같은 결과가 나옵니다.

Rust 커널이 없으면(`cargo`가 없는 설치) 같은 알고리즘의 numpy 구현이 돌아갑니다. 다만 느려서, 쌍당 샘플 수를 5만 이하로 제한합니다.

## 속도

PS 반복단위–톨루엔을 기준으로 잰 시간입니다.
- 쌍당 20만 접촉 + 2,000 클러스터(기본값): 약 5초
- 쌍당 50만 + 5,000: 약 10초

## 검증

**식과 커널의 정확성**(`tests/test_blends.py`, `native/src/lib.rs` 테스트)
- 크기가 같고 ε만 다른 LJ 구에서, χ가 기하평균 규칙 식 ½Z(2√(ε₁ε₂) − ε₁ − ε₂)f(r)/RT와 정확히 같고 양수입니다.
- Rust로 계산한 접촉 배치와 에너지가 numpy 식과 10⁻⁹ 안에서 같습니다.
- 모든 접촉이 정확히 반지름 합에서 닿습니다.
- 같은 구 주위의 배위수는 12(접촉수 한계)를 넘지 않고 7–10 사이입니다.
- 같은 통계를 넣으면 χ = 0이 됩니다.

**물리적 타당성**
비교 조건은 다음과 같습니다.
- PS 반복단위(에틸벤젠으로 막음)와 용매 10종, 298 K
- 쌍당 50만 접촉, 5,000 클러스터, 시드 2개 평균
- 비교 대상은 같은 엔탈피 성분인 Hansen χ_H = V·Ra²/(4RT)입니다. PS HSP는 18.5/4.5/2.9입니다.

| 용매 | Hansen χ_H | 접촉 χ_H (± 시드 간 표준편차) |
|---|---|---|
| 톨루엔 | 0.12 | 0.18 ± 0.19 |
| 벤젠 | 0.19 | 0.37 ± 0.15 |
| 클로로포름 | 0.10 | −2.99 ± 0.21 |
| 사이클로헥산 | 0.43 | −1.14 ± 0.17 |
| 헥산 | 1.07 | −2.30 ± 0.47 |
| 에틸 아세테이트 | 0.48 | 2.70 ± 0.19 |
| THF | 0.32 | 1.77 ± 0.18 |
| 아세톤 | 0.65 | 4.45 ± 0.11 |
| 에탄올 | 1.89 | 3.71 ± 0.14 |
| 메탄올 | 1.98 | 7.18 ± 0.13 |

- **순위 상관**: Spearman ρ = 0.65(p = 0.04). 비용매(알코올·아세톤)는 크게, 방향족 용매는 작게 나오는 흐름은 맞습니다.
- **체계적 오차**
  - 지방족 용매(헥산, 사이클로헥산)와 클로로포름은 부호가 틀립니다.
  - 극성 용매는 3–5배 크게 나옵니다.
- **원인**
  - 쌍 하나의 볼츠만 평균은 가장 잘 붙는 배향이 좌우합니다. 그래서 방향족 고리의 포개짐(기준–기준)과 쌍극자 정렬(극성 용매끼리)의 비중이 실제 액체보다 훨씬 큽니다.
  - 실제 액체에서는 이웃들이 서로 자리를 다투기 때문에 모든 접촉이 최적 배향일 수 없습니다.
  - 같은 이유로 벤젠–사이클로헥산(실험적으로 흡열 혼합, χ_H ≈ +1.3)도 음수로 나옵니다.
- **반지름 배율의 영향**: `contact_scale`을 1.1–1.2로 늘리면 크기는 줄지만 부호 문제는 남습니다.

결론적으로 이 계산은 **탐색용**입니다. 비슷한 화학 계열 안에서 순위를 비교하는 데 쓰고, 절대값이나 상용/상분리 판정은 실험이나 MD(응집 에너지 밀도)로 확인해야 합니다.

## 사용

- **UI**: 연구 데이터 → 빠른 예측의 "분자 접촉 χ (Blends 방식, 실험적)"
- **API**: `POST /api/research/screening/blend-contacts`
  ```json
  {"base_smiles": "*CC(*)c1ccccc1", "screen_smiles": "Cc1ccccc1", "samples": 200000, "clusters": 2000,
   "temperatures": [250, 300, 350, 400], "n_base": 1000, "n_screen": 1}
  ```
- **MCP**: `blend_chi_contacts`
- **설치**: `setup.sh`가 `cargo`를 찾으면 `pip install ./native`로 Rust 커널을 빌드합니다. Rust는 https://rustup.rs 에서 설치합니다.
