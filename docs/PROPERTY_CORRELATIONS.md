# 구조 기반 물성 상관식 (Synthia 방식)

Materials Studio Synthia는 반복단위 구조만으로 Tg, 밀도, 용해도 파라미터 같은 물성을 몇 초 안에 추정합니다. 바탕은 Bicerano의 연결성 지수 상관식(*Prediction of Polymer Properties*)입니다. Polymer Lab은 이 방식을 공개 문헌의 정의로 새로 구현합니다(AGENTS.md 원칙 7). Synthia의 파일·파라미터는 쓰지 않습니다.

## 현재 구현: 연결성 지수 (`native/src/topology.rs`, `workbench/correlations.py`)

- **그래프:** 반복단위 SMILES(`[*]…[*]`)의 수소를 뺀 그래프입니다. 두 연결점 원자를 결합 하나로 이어 고리로 닫습니다(두 연결점이 한 원자면 자기 고리). 이렇게 하면 모든 원자가 무한히 긴 사슬 가운데에서와 같은 이웃을 가지므로, 지수는 **반복단위당 값**이 됩니다.
- **지수:** Randić(*J. Am. Chem. Soc.* 97, 6609, 1975), Kier–Hall(*Molecular Connectivity in Chemistry and Drug Research*, 1976)의 정의를 씁니다.
  - χ⁰ = Σ δ^(-1/2)
  - χ¹ = Σ_결합 (δᵢδⱼ)^(-1/2)
  - 원자가 지수의 δᵛ = (Zᵛ − h)/(Z − Zᵛ − 1)입니다. 2주기까지는 분모가 1입니다.
  - 형식 전하는 RDKit처럼 무시합니다.
- **주쇄:** 닫는 결합이 속한 블록(biconnected component)의 원자입니다. 두 연결점 사이 경로에 있는 모든 원자이며, 주쇄의 고리(페닐렌 등)는 통째로 들어가고 한 결합으로 매달린 곁사슬은 빠집니다. 이 정의는 그래프 정의이며, Bicerano의 구조 파라미터 정의와 맞는지는 원 출처로 확인해야 합니다.
- **출력:** 네 지수, 원자별 δ·δᵛ·주쇄 여부, 주쇄·곁사슬 원자 수, 반복단위 몰질량을 줍니다. 물성 값은 아직 내지 않습니다.

예: 폴리스티렌 `[*]CC([*])c1ccccc1`은 χ⁰ 5.397341, χ¹ 3.966326, χ⁰ᵛ 4.671208, χ¹ᵛ 3.015855, 주쇄 2·곁사슬 6원자입니다. 폴리에틸렌 `[*]CC[*]`은 χ⁰ = χ⁰ᵛ = √2, χ¹ = χ¹ᵛ = 1입니다.

## 아직 없는 것

- **물성 상관식(Tg, 몰부피·밀도, 응집 에너지·용해도 파라미터 등):** 계수와 구조 파라미터(극성기·회전 자유도 등)의 정의를 Bicerano의 원 출처(책 3판, 2002, 또는 원 논문)에서 식·표 번호와 함께 확인한 뒤 넣습니다. 계수를 기억에 의존해 넣지 않습니다. 이 클라우드 환경의 네트워크 정책이 문헌 사이트를 막고 있어 아직 확인하지 못했습니다.
- **Bicerano 고유 δᵛ:** 일부 원소(예: 산화 상태가 다른 S, Si)에 대한 책의 별도 δᵛ 값이 있는지 원 출처로 확인해야 합니다. 지금은 Kier–Hall 식 그대로이며 RDKit과 같습니다.
- **적용 범위:** 상관식은 선형 비정질 고분자 기준입니다. 가교 에폭시는 별도 식이 필요하며 따로 다룹니다.
