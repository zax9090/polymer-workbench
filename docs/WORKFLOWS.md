# 연결된 벌크 연구 흐름

`workbench/workflows.py`(단계·경로), `workbench/autopilot.py`(승인한 계획 실행), `workbench/workflow_api.py`(HTTP)의 설계와 검증 기록입니다. 사용법은 `docs/MANUAL.md`의 "연결된 벌크 연구 흐름"에 있습니다.

## 계산 경로와 연결 설정

경로는 템플릿으로 정해집니다(`workflows.detect_route`). 설계 인자는 그 경로의 코드가 실제로 읽는 설정에만 연결할 수 있습니다.

| 경로 | 템플릿 | 연결 설정 (허용 범위) | 결과 파일 |
|---|---|---|---|
| `gaff2_bulk` | 벌크, GAFF2, 자체 셀 빌더 | 온도(100~500 K), 초기 패킹 밀도(0.3~1.2), 반복단위 수(2~200, 정수), 사슬 수(2~16, 정수) | `bulk_complete.json` |
| `pcff_bulk` | 벌크, PCFF | 온도, 반복단위 수, 사슬 수 (`pcff.bulk`가 읽는 값) | `bulk_complete.json` |
| `crosslink` | 가교 | 경화 온도(300~600 K), 목표 전환율(0.05~0.99), 반응 거리(3~6 Å), 2차 아민 확률(0.05~1), 샘플링 온도, 수지(2~400)·경화제(1~400) 분자 수 (`crosslink.cure`가 읽는 값) | `cure_complete.json` |
| `tg_scan` | 앞 흐름의 완료된 셀마다 `atomistic_mode: tg_scan` | 앞 흐름의 인자 그대로 | `tg_complete.json` |

- 정수 설정은 모든 설계점이 정수여야 흐름을 만들 수 있습니다. 회귀는 연속 인자로 하고, 추천값의 정수 설정을 가장 가까운 정수로 반올림한 조건(`recommendation.rounded`)에서 같은 모델로 예측값·예측구간을 다시 구합니다. 확인 계산은 반올림한 조건으로 실행하고 그 예측과 비교합니다.
- 허용 범위를 벗어난 행은 행 번호·설정 이름·값·허용 범위를 담은 한국어 422로 거부합니다.
- Tg 스캔 흐름의 확인 계산은 추천 조건으로 앞 경로의 셀을 새로 계산한 뒤 그 셀을 스캔합니다(계산 2개, `scan_job_id`). 계획 실행의 최대 계산 수에도 2개로 셉니다.

## 반응값과 출처

| 반응값 | 단위 | 출처 | 최적화 전에 다시 확인하는 것 |
|---|---|---|---|
| `final_frame_density` | g/cm³ | 최종 구조의 자유 부피 분석(`research/analyses/<ID>`) | 분석 기록 해시, 분석 매개변수, 커널·코드 해시, 원본 구조 파일 SHA-256, 값 |
| `probe_accessible_fraction` | 1 | 같은 분석, 첫 탐침 | 같음 |
| `npt_density` | g/cm³ | 작업 폴더 `bulk_complete.json`의 NPT 표본 평균 | 파일 SHA-256, 값 |
| `bulk_modulus` | GPa | 같은 파일, 부피 요동 | 같음 |
| `volume_expansion` | 1/K | 같은 파일 | 같음 |
| `epoxide_conversion` | 1 | `cure_complete.json`의 최종 에폭시 전환율(가교) | 파일 SHA-256, 값 |
| `tg_kelvin`, `expansion_glass`, `expansion_melt` | K, 1/K | Tg 스캔 작업의 `tg_complete.json`. `transition_resolved`가 아니면 값을 쓰지 않고 분석 실패 | 파일 SHA-256, 값, 전이 확인 |

- 행 하나의 관측(`observation`)에는 대표 반응값(`value`, 예전 기록과 호환)과 모든 반응값(`values`, `units`)이 함께 들어갑니다. NPT 값에는 RadonPy 수렴 판정(`equilibrated`)과, 수렴하지 않았을 때의 경고가 붙습니다.
- 모든 관측과 확인 결과는 `verified=false`입니다. 측정값 저장소에 등록하지 않습니다.
- 단일 반응 최적화는 고른 반응값 하나로 반응표면을 맞춥니다. 만족도 최적화는 반응마다 모델을 맞추고 Derringer–Suich D를 최대화합니다(`docs/DOE_MIXTURE.md`). 확인 계산은 목표를 정한 반응마다 예측과의 차이(`prediction_errors`)를 기록합니다.

## 승인한 계획 실행

계획(행, 같은 설정의 시도 횟수 1~3, 허용 실패 행 수, 단일 반응 또는 만족도 목표, 확인 계산, 보고서, Drive 업로드)과 승인 예산을 한 번 받으면 끝까지 진행합니다.

- 최대 계산 수 = 계획한 행 중 관측이 없는 행마다 (시도 횟수 − 이미 쓴 시도) + 확인 계산이면 시도 횟수. 승인 예산은 이 값 이상, 흐름의 남은 예산 이하여야 합니다.
- 재시도는 `failed`, `interrupted`만, 같은 설정·시드로 합니다. `blocked`는 즉시 멈추고, `cancelled`·기록 없음은 재시도하지 않습니다. 실패 행이 허용 수를 넘으면 멈춥니다. 허용 안의 실패 행과 계획 밖 행은 사유를 적어 최적화에서 제외합니다.
- 실행 중 같은 흐름의 직접 단계 실행은 409로 막습니다. 승인 시각·요청자 표시·계획 해시와 단계 기록이 흐름 기록에 남습니다. 서버 재시작 뒤에는 `interrupted`이며 같은 계획을 다시 승인하면 이어 갑니다.

## 한계

- 연결 경로는 GAFF2 자체 벌크, PCFF 벌크, 에폭시–아민 가교와 그 셀의 Tg 스캔입니다. RadonPy 기본 셀 빌더의 GAFF2 벌크, Martini 혼합계 등은 연결하지 않았습니다.
- 정수 설정의 반올림 확인은 연속 모델의 예측을 씁니다. 정수 격자 위의 최적점을 따로 찾지는 않습니다.
- 경로 시험은 즉시 끝나는 합성 작업입니다. EMC·LAMMPS로 PCFF·가교·Tg 흐름을 끝까지 돌린 기록은 없습니다.
- NPT 물성은 계산 하나의 표본 구간 평균입니다. 짧은 계산의 체적 탄성률·팽창 계수는 수렴값이 아니며, 반복 계산의 산포는 설계의 반복점으로만 드러납니다.
- 만족도 D는 사용자가 정한 경계 아래의 순위입니다. 반응 사이의 상관과 예측 불확실성은 D에 반영하지 않습니다.
- 실제 MD로 계획 실행을 끝까지 돌린 기록은 아직 없습니다.
