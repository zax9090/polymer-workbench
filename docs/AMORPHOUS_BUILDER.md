# 자체 비정질 셀 빌더

GAFF2 비정질 벌크 셀에서 `cell_builder: "native"`를 고르면 RadonPy의 `amorphous_cell` 대신 Polymer Lab이 직접 사슬을 셀 안에 키웁니다(`workbench/amorphous.py`). 이 파일은 numpy와 RDKit만 쓰며, 작업 폴더에 `native_amorphous.py`로 복사되어 계산 기록에 함께 남습니다. 기본값은 지금처럼 `radonpy`입니다.

## 기존 프로그램에서 확인한 것

REA로 받은 RadonPy 휠의 `radonpy/core/poly.py`와 EMC 9.4.4가 만든 `build.emc`를 읽었습니다.

- **RadonPy `amorphous_cell`**
  - 사슬 형태 하나를 무작위로 회전·이동해 복사하므로 모든 사슬의 형태가 같습니다.
  - 0.05 g/cm³로 배치한 뒤 패킹 단계에서 가열(최고 700 K)과 압축으로 0.8 g/cm³까지 밀어 넣습니다.
  - 겹침 검사(`check_3d_structure_cell`)는 좌표를 상자 안으로 접은 뒤 일반 거리만 재므로, 주기 경계 너머의 접촉을 놓칩니다.
- **EMC `build`**
  - 목표 밀도(0.5 g/cm³)에서 사슬을 직접 키웁니다.
  - 한 단계마다 후보 20개를 결합·비결합 에너지로 고릅니다(`grow method energetic, ntrials 20`).
  - 다 놓은 뒤 이완(`relax`) 과정을 거칩니다.

## 알고리즘

1. **조각 나누기**
   - RDKit의 엄격한 회전 결합 패턴으로 사슬을 단단한 조각으로 나눕니다.
   - 고리, 다중 결합, 아미드는 조각 안에 남아 템플릿 모양을 그대로 유지합니다.
   - 사슬 끝에서 시작하는 너비 우선 순서로 조각을 정렬합니다.
2. **좌표 정하기**
   - 각 조각은 이미 놓인 부모 원자들에 템플릿 좌표를 맞춰(Kabsch) 놓습니다.
   - 그다음 연결 결합을 축으로 비틀림각 후보 12개(막히면 48개)를 만듭니다.
   - 이 방식에서 결합 길이와 결합각은 템플릿 값과 정확히 같습니다(오차 10⁻¹⁴ Å).
3. **점수 매기기**
   - 후보마다 이미 놓인 모든 원자와의 겹침 에너지를 최소 이미지 규약으로 계산합니다. 겹침의 기준은 Bondi 반지름 합의 0.75배이고, 같은 사슬에서 3결합 이내인 원자 쌍은 뺍니다.
   - 이 회전이 다음 조각의 첫 원자 위치까지 정하므로, 그 원자도 함께 점수에 넣습니다. 이것이 빠지면 폴리에틸렌처럼 조각이 탄소 하나와 수소 둘인 사슬이 자기 자신을 뚫습니다.
   - exp(−U) 가중치로 후보 하나를 고릅니다(Rosenbluth).
4. **막다른 단계 처리**
   - 모든 후보가 5 kT 이상이면 그 사슬의 조상 조각을 점점 더 깊이 되돌려 다시 키웁니다(최대 8회).
   - 그래도 막히면 가장 나은 후보를 받아들이고 `unresolved_steps`로 기록합니다.
5. **성장 순서**
   - 모든 사슬을 한 조각씩 번갈아 키웁니다. 뒤에 놓는 사슬이 빈자리를 못 찾는 일을 줄이기 위해서입니다.
   - 각 사슬의 첫 조각은 무작위 위치 30곳 중 가장 덜 붐비는 곳에 놓습니다.
6. **이후 계산**
   - 셀은 처음부터 목표 밀도(`build_density`, 기본 0.8 g/cm³)입니다.
   - 그래서 RadonPy 패킹 단계의 가열과 압축 대신 최소화 → 0.1 fs NVT 2만 스텝 → 1 fs NVT 10만 스텝을 실행하고, 이어서 RadonPy의 21단계 평형화와 NPT 샘플링을 그대로 따릅니다.
   - 단계 길이 배율이 함께 적용됩니다.

결과의 `metadata.builder`에는 원자 수, 상자 크기, 되돌린 횟수, 해결하지 못한 단계, 가장 가까운 비결합 접촉, 1.2 Å 미만 접촉 수가 남습니다.

## 검증

| 확인 항목 | 결과 |
|---|---|
| 결합 길이·결합각 보존 | 모든 사슬에서 템플릿과 같음(테스트) |
| 같은 시드 재현성 | 같은 좌표(테스트) |
| 주기 경계 너머 접촉 | 최소 이미지로 잡음(테스트) |
| 사슬마다 다른 형태 | 원자 간 거리 분포가 사슬마다 다름(테스트) |
| 빌드 시간 | PE·PS·PMMA, 사슬 8–10개, 약 1,300원자, 0.5–1.0 g/cm³에서 1–7초 |
| 압축 준비 단계 LAMMPS 시간 | PS 10량체 × 8(1,296원자), 단계 길이 5%: RadonPy 101,028스텝 26.6초 → 자체 빌더 6,194스텝 1.9초 |
| 20 ps NPT 뒤 밀도 | PS 10량체 × 8: RadonPy 셀 0.927, 자체 셀 0.928 g/cm³. 고리를 꿰뚫은 결합은 둘 다 0개 |

RadonPy의 압축 단계는 밀도가 끝에서야 높아져 한 스텝이 쌉니다(평균 0.26 ms). 그래서 전체 시간 절약은 단계 길이 배율 1에서 이 크기 기준 약 8분 → 2분 정도입니다. 이 빌더의 더 큰 장점은 시간보다 셀의 품질입니다. 사슬마다 형태가 처음부터 서로 다르고, 주기 경계를 고려해 겹침을 검사합니다.

## 한계

- 겹침 에너지만 보는 무열(athermal) 성장입니다. 비틀림 에너지(trans/gauche 선호)는 쓰지 않습니다.
- 성장 직후에는 1.2 Å 미만의 접촉이 수십 개 남을 수 있습니다. 이것은 이어지는 최소화가 풉니다.
- 지금은 GAFF2 경로에만 연결했습니다. PCFF와 가교 경로는 아직 EMC가 셀을 만듭니다.
