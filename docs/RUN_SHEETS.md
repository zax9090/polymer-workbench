# 실행표 (paste-to-run sheets)

실행표는 붙여넣기만으로 계산을 시작하는 줄 단위 설정 목록입니다. 코드가 아니므로 어떤 줄도 평가·실행되지 않습니다. 구현은 `workbench/sheets.py`(형식 해석·실행), `workbench/sheet_api.py`(HTTP), MCP `run_sheet`, 화면 `workbench/static/sheets.js`입니다.

## 형식 v1

- 첫 내용 줄: `# Polymer Lab 실행표 v1` (대소문자·공백 차이는 허용)
- 이후: 한 줄에 `키: 값` 하나. 전각 콜론 `：`도 허용
- `#`로 시작하는 줄, 빈 줄, ``` 로 시작하는 줄(채팅에서 복사할 때 딸려 오는 코드 울타리)은 건너뜀
- 공통 키: `종류`(blends·블렌드 / 작업·jobs, 필수), `이름`(80자), `메모`(500자)
- 한 번만 쓰는 키를 두 번 쓰면 오류. `기준`·`대상`·`공통`·`작업`만 여러 번 씀
- 영어 키 별칭: kind, name, note, base, screen, temperatures, samples, clusters, seed, cap, contact_scale, common, job

### 종류: blends

| 키 | 값 | 기본·범위 |
|---|---|---|
| `기준` · `대상` | `이름 \| SMILES \| 중합도=N` (이름 생략 시 SMILES가 이름, 중합도 생략 시 1) | 각 성분 이름 중복 불가, SMILES 500자, 중합도 1~1e6 |
| `온도` | `300, 350, 400` 또는 `250~450/25` (K 표기 허용) | 생략 시 250~500 K, 25 K 간격. 50~1000 K, 200개 이하, 중복 불가 |
| `표본` | 정수(`200,000` 허용) | 200000, 1000~2000000 |
| `클러스터` | 정수 | 2000, 20~5000 |
| `시드` | 정수 | 1 |
| `말단` | 수소·메틸 | 수소 |
| `접촉배율` | 숫자 | 1.0, 0.8~1.5 |

조합은 기준 × 대상(최대 100개). 기준과 대상의 SMILES가 같은 조합은 오류입니다. 각 조합은 `blend_chi`와 같은 매개변수로 `execution.compute("blend_contacts")`(구조·접촉 분석 줄)에서 하나씩 계산합니다. 순위는 `chi_reference`(실행표 온도 중 298.15 K에 가장 가까운 온도의 χ) 오름차순입니다. χ가 낮을수록 섞이는 쪽이지만 섞임을 확정하지 않으며, 방법의 한계는 `docs/BLENDS.md`를 따릅니다.

### 종류: 작업

| 키 | 값 |
|---|---|
| `공통` | `설정=값 \| 설정=값 ...` 모든 작업에 적용. 여러 줄 가능, 같은 설정을 두 번 쓰면 오류 |
| `작업` | `이름 \| 설정=값 \| ...` 첫 칸은 작업 이름(80자, 중복 불가). 개별 설정이 공통 설정보다 우선 |

설정 이름은 `JobConfig`(`workbench/models.py`) 필드 이름입니다. `name`(첫 칸에 씀)과 긴 입력(`engine_input`, `mdp_text`, `forcefield_itp_text`, `pdb_text`, `a3m_text`)은 쓸 수 없습니다. 작업 이름은 `실행표 이름 · 작업 이름`(120자를 넘으면 작업 이름만)으로 저장됩니다. 작업은 최대 50개입니다.

각 작업은 `preflight.prepare_submission`을 거칩니다. 이 함수는 `POST /api/jobs`와 같은 코드이며 Tg 스캔·PACKMOL·혼합계의 원본 작업 파일 확인과 화학·원자 수·엔진 검사를 합니다. 하나라도 오류가 있으면 아무 작업도 만들지 않습니다. 작업 ID는 미리 정해 저장하므로 제출이 중간에 끊겨도 이어서 실행할 때 같은 작업이 두 번 생기지 않습니다.

## 오류

검사 결과는 `{line, message, text}` 목록입니다. 메시지는 한국어이고, 공통 설정이 틀리면 작업마다 반복하지 않고 그 공통 줄에 한 번만 `[공통]`으로 표시합니다. 모든 줄을 한 번에 검사합니다. 예외는 빈 실행표, 크기 초과(10만 자·2000줄), 첫 줄 오류, `종류` 누락으로, 이 경우에는 바로 멈춥니다.

## 저장과 상태

`<데이터 폴더>/research/sheets/<id>/`에 다음을 저장합니다.

- `sheet.txt`: 붙여넣은 원문 바이트. SHA-256은 기록에 남깁니다.
- `record.json`
- `pairs/<i>.json`: Blends 조합별 `blend_chi` 전체 결과
- `results.csv`: UTF-8 BOM, CSV 수식 주입 방지 처리

Blends 실행표의 상태는 다음과 같습니다.

- `queued` → `running` → `completed`: 하나라도 끝났거나 실패한 경우입니다.
- `failed`: 모두 실패한 경우입니다.
- `cancelled`: 사용자가 취소한 경우입니다.
- `interrupted`: 앱 종료, 실행 관리자 취소 또는 재시작으로 멈춘 경우입니다. 남은 조합은 `pending`으로 둡니다.

`resume`은 `pending` 조합만 다시 돌립니다. 실패한 조합은 같은 입력이면 같은 결과가 나오므로 다시 돌리지 않습니다.

작업 실행표의 상태는 다음과 같습니다.

- `submitting` → `submitted`
- 진행 상황(`progress`)은 각 작업의 `job.json`에서 매번 읽습니다.

## 검증 기록 (2026-10-24, `tests/test_sheets.py`, 7개 통과)

- 예제 3개(`TEMPLATES`: PS 용매 5종, PS 블렌드 3종(중합도 100), GAFF2 자체 벌크 4작업)가 모두 검사를 통과합니다. 벌크 작업의 예상 원자 수는 PE 496, PS 1296개입니다.
- Blends 실행표의 조합 결과는 같은 매개변수의 직접 `blend_chi` 호출과 **정확히 같습니다**(`chi_reference`, 온도별 χ, A + B/T 적합). 대상은 PE 반복단위(중합도 50) × 메탄올·에테인, 표본 3000, 시드 5, 280/300/320 K입니다. 임계 χ는 Flory–Huggins 식 0.5(1/√50 + 1)²과 같습니다.
- 작업 실행표의 공통·개별 설정이 작업 설정에 그대로 들어가고, `submitted_via`는 `sheet:<id>`입니다. 취소하면 대기 작업이 모두 취소됩니다.
- 중단된 실행표는 새 관리자에서 `interrupted`가 되고, 이어서 실행하면 남은 조합만 계산합니다. 실패는 기록하고 순위에서 뺍니다.
- MCP `run_sheet`의 검사, 실행, 상태, 목록, 예제를 확인했습니다.

## 남은 일 (중간 정지 시점)

- 화면(`sheets.js`)은 연결했으나 실제 앱에서 Blends 실행과 결과 표를 끝까지 눌러 보지 않았습니다. API·MCP 경로는 테스트로 확인했습니다.
- 작업 실행표로 실제 엔진(LAMMPS) 작업을 돌려 보지 않았습니다. 사용자 PC에서 `jobs_bulk` 예제로 확인할 차례입니다.
- 후속 후보는 다음과 같습니다. 실행표 종류(DoE 설계·연구 흐름), 작업 실행표 결과 요약 표(밀도 등), 예제를 앱 밖 텍스트 파일로 내려받기.
