# 혼합물 실험과 다중 반응 만족도

Minitab의 혼합물 설계·분석과 반응 최적화(만족도)에 해당하는 기능을 공개 문헌의 정의로 새로 구현했습니다(AGENTS.md 원칙 7). 계산은 Rust(`native/src/mixture.rs`, `native/src/doe.rs`)가 하고, 기록과 CSV는 `workbench/doe.py`가 맡습니다.

## 방법과 출처

| 기능 | 정의 | 출처 |
|---|---|---|
| 심플렉스 격자 {q, m} | 각 성분 비율이 0, 1/m, …, 1이고 합이 1인 모든 점. 점 수 C(q+m−1, m) | Scheffé, *J. R. Stat. Soc. B* 20, 344 (1958) |
| 심플렉스 중심 | 공집합이 아닌 모든 성분 부분집합의 중심. 점 수 2^q − 1 | Scheffé, *J. R. Stat. Soc. B* 25, 235 (1963) |
| 꼭짓점 설계 | L ≤ x ≤ U, Σx = 1 영역에서 성분 q−1개를 경계에 두고 나머지 하나가 범위 안이면 꼭짓점. 차수 2는 같은 모서리(공통 활성 경계 q−2개 이상) 꼭짓점 쌍의 중점을 더함 | McLean & Anderson, *Technometrics* 8, 447 (1966) |
| 축 점검 배합 | 전체 중심과 각 꼭짓점의 중간 | Cornell, *Experiments with Mixtures*, 3판(Wiley, 2002) |
| L-유사성분 | z = (x − L)/(1 − ΣL). 하한은 Σx = 1로 더 조여진 값을 씀 | 같은 책 |
| Scheffé 모델 | 절편 없는 1차 Σβᵢzᵢ, 2차 + Σβᵢⱼzᵢzⱼ, 특수 3차 + Σβᵢⱼₖzᵢzⱼzₖ | Scheffé (1958, 1963) |
| 만족도 | 최대화 d = ((y−L)/(T−L))^s, 최소화 d = ((U−y)/(U−T))^t, 목표값은 양쪽. D = (Π dᵢ^rᵢ)^(1/Σrᵢ), 하나라도 0이면 D = 0 | Derringer & Suich, *J. Qual. Technol.* 12, 214 (1980) |

- **적합:** 기존 DoE와 같은 열 피벗 Householder QR입니다. 성분 합이 1이라 상수항이 모델 공간에 들어 있으므로, R²와 회귀 F는 평균 기준(중심화)으로 계산합니다. 1차 혼합 계수는 순수 (유사)성분의 예측 반응이므로 0 검정을 하지 않습니다.
- **최적화:** 혼합물은 두 성분 사이에서 비율을 주고받는 방향(합 1 유지)으로 선 탐색을 합니다. 시작점은 꼭짓점, 중심, 축 점, 무작위 실행 가능점 48개입니다. 공정 인자는 좌표별 선 탐색입니다. 경계에서 10⁻¹⁰ 안의 값은 경계로 맞춥니다. 전역 최적을 보장하지 않습니다.

## 검증 (2026-10-23)

| 항목 | 결과 |
|---|---|
| 설계 점 수 | q = 2~6, m = 1~4 격자가 C(q+m−1, m), 심플렉스 중심이 2^q − 1 (Rust), 모든 점의 합 1 |
| 꼭짓점 설계 | x₁ ≤ 0.6으로 자른 삼각형에서 꼭짓점 4개·모서리 중점 4개. 하한만 있으면 L-심플렉스의 꼭짓점 3개. 생성한 모든 점이 선언한 범위 안 |
| statsmodels 0.14.5 OLS(절편 없음)와 대조 | 무작위 60건(3~5성분, 절반은 하한 있음, 1차·2차·특수 3차, 축 점·중심 포함 2회 반복): 계수 최대 상대 차이 3.0×10⁻¹⁴, 표준오차 1.9×10⁻¹⁴, 2·3차 항 p값 1.5×10⁻¹³, 중심화 R² 1.1×10⁻¹⁶, 회귀 F 1.8×10⁻¹⁵, 개별 예측구간 2.8×10⁻¹⁴ (`scripts/crosscheck_mixture_statsmodels.py`) |
| numpy 최소제곱과 대조(저장소 테스트) | 계수·표준오차·R²·잔차 자유도·순수 오차 자유도가 같음 |
| 유사성분 불변성 | 하한 (0.2, 0.1, 0)에서 유사성분으로 맞춘 적합값이 실제 비율로 맞춘 값과 10⁻⁹ 안으로 같음(2차 Scheffé 공간은 아핀 변환에 닫혀 있음) |
| 알려진 최적점 | f = 10A + 8B + 6C + 12AB + 4AC − 6BC의 최대는 A–B 모서리의 A = 7/12(값 12.0833). 추천 배합 (0.583, 0.417, 0), 예측 12.083 |
| 만족도 | 손계산(d = 0.5, 모양 지수 2에서 0.25, 중요도 1:3의 D = 0.5)과 같음. 공정 인자 2개 예제에서 두 목표를 모두 만족하는 점(D = 1)을 찾음. 혼합물 2반응 예제에서 D가 관측한 모든 실험의 D 이상 |
| 화면 | Chromium 1360·390 px에서 설계 생성 → 분석·삼각 색 지도 → 만족도 최적화, 콘솔 오류와 가로 넘침 없음 |

## 한계

- 블록, 공정 변수와 혼합물 성분을 함께 쓰는 설계, 성분 사이의 일반 선형 제약(예: A + B ≤ 0.6)은 아직 지원하지 않습니다.
- 꼭짓점 설계의 모서리 판정은 활성 경계 수로 합니다. 퇴화한 꼭짓점이 많은 영역에서는 생성 점을 확인하세요.
- 만족도는 반응마다 따로 맞춘 모델의 예측값으로 계산합니다. 반응 사이 상관과 예측 불확실성은 D에 반영하지 않습니다.
- 추천 배합과 만족도 최적점은 모두 확인 실험 전의 후보입니다.
