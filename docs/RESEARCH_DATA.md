# 연구 데이터와 출처 관리

0.3은 원본 계산 폴더를 유지하면서 별도 `research/research.duckdb`에 색인을 추가합니다. 새 작업은 완료 후 자동 색인하고, 기존 작업은 시작 시 또는 연구 데이터 화면의 새로 색인 기능으로 읽습니다. 데이터베이스에는 실험 행과 측정값 행을 분리합니다. 작업 결과의 재분석 실패는 성공한 계산 상태를 실패로 바꾸지 않습니다.

## 재료와 측정값

재료 ID는 정규화된 SMILES와 명시한 사슬 길이·서열·입체규칙성·조성 등의 JSON으로부터 계산한 SHA256입니다. 같은 반복단위라도 명시한 사슬 길이나 준비 조건이 다르면 보수적으로 구분합니다. 자동으로 화학적 동등성을 증명하지 않습니다. 일반 CG 비드는 특정 화학종에 매핑되지 않으므로 실제 실험 물성과 직접 연결할 수 없습니다.

측정값에는 재료 또는 색인된 작업 ID, 물성, 수치, 단위, 측정법, 조건, 출처, 출처 유형, 검토 여부가 필요합니다. Tg는 K, 탄성률·인장강도는 MPa, 결합 친화도는 해리상수 Kd(nM), RMSD는 Å로 정규화하며 원래 값·단위도 보존합니다. 기본 검토 상태는 false입니다. 검토 전 값과 demo/simulation 값은 실험 대리 모델 학습에서 제외합니다.

CSV 열 예시는 아래와 같습니다. JSON 값에 쉼표가 포함되면 표준 CSV 따옴표 규칙으로 감싸야 합니다. 업로드는 미리보기 이후 별도 저장 단계가 있으며 일부 행이 유효하지 않으면 전체 저장을 취소합니다.

```text
repeat_smiles,property,value,unit,method,source,origin
[*]CC[*],tg,80,C,DSC,사용자 실험 노트 17,experimental
```

이 예시 수치는 형식을 설명하기 위한 값이며 실제 고분자의 물성이 아닙니다. `material_json`과 `conditions_json` 열로 재료의 추가 구분 정보와 측정 조건을 입력할 수 있습니다. CSV의 검토 상태는 업로드만으로 승인되지 않습니다.

## 궤적 피처

- Rg는 토폴로지로 구분한 각 사슬의 질량 중심 기준 회전반경입니다. 서로 떨어진 여러 사슬을 하나의 사슬로 처리하지 않습니다.
- 말단 거리·접선 상관·이면각 엔트로피는 검증 가능한 선형 주사슬이 있을 때만 계산합니다. 분지·고리 구조에서 임의로 말단을 추측하지 않습니다.
- 이면각 값은 고정 구간 히스토그램의 이산 엔트로피이며 열역학적 엔트로피가 아닙니다. 접선 상관도 지속 길이의 직접 추정값이 아닙니다.
- 쌍극자 변동은 전하가 명시된 중성 사슬의 실제 동역학 프레임에 한정합니다. 구조 생성·최소화의 두 장면을 MD 표본으로 간주하지 않습니다.
- PyMBAR의 탐지값은 특정 관측량에 대한 통계적 절단점 후보입니다. 물리적 평형을 증명하지 않으며 항상 `equilibrated: false`를 유지합니다.
- 단백질 RMSD·접촉·수소결합·SASA·RDF는 현재 자동 궤적 분석 대상이 아닙니다. 필요한 원자 선택·기준 구조·절단 거리·정규화 조건이 없으면 누락 사유를 기록합니다. 관련 측정값은 출처·방법·조건과 함께 별도로 입력할 수 있습니다.

## 실험 곡선과 PDF

DSC는 사용자가 고른 두 선형 기준선 사이에서 열 흐름의 중간 교차 온도를 구합니다. 가열 속도·이력·흡열 피크의 영향을 검토한 뒤 측정값으로 저장해야 합니다. 인장 곡선은 사용자가 지정한 변형률/응력 단위와 선형 구간의 회귀 기울기를 사용합니다. 기기 컴플라이언스·시편 치수·toe 보정은 자동 적용하지 않습니다. TGA/GPC는 곡선 미리보기만 제공합니다.

PDF는 최대 10 MB·100페이지에서 텍스트를 추출하고 원본 파일·SHA256·페이지 번호를 보관합니다. 표와 그림의 의미를 추론하거나 자동 측정값을 등록하지 않습니다. 스캔 문서의 OCR, 외부 LLM 호출, 유료 문헌 데이터 수집은 수행하지 않습니다.

## 일관된 백업

프로세스/스레드 잠금으로 DuckDB 접근을 직렬화합니다. 내보내기는 하나의 읽기 트랜잭션에서 `experiments_master.parquet`와 `measurements.parquet`를 만들고, 개수·해시를 가진 `metadata.json`과 함께 새 폴더에 게시합니다. 동일 파일을 변경하는 실시간 클라우드 DB 동기화 방식이 아닙니다.

스냅샷 ZIP에는 두 테이블과 메타데이터가 들어갑니다. 큰 원본 궤적·로그·PDF는 별도로 보관되므로 계산별 ZIP도 함께 백업해야 전체 원본을 복원할 수 있습니다. 이미 설정된 Drive/rclone 동기화 폴더에 스냅샷을 복사할 수 있지만 원격 업로드 완료 여부는 그 동기화 프로그램에서 확인해야 합니다.
