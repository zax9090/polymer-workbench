# 연구 데이터와 출처 관리

0.3은 원본 계산 폴더를 유지하면서 별도 `research/research.duckdb`에 색인을 추가합니다. 새 작업은 완료 후 자동 색인하고, 기존 작업은 시작 시 또는 연구 데이터 화면의 새로 색인 기능으로 읽습니다. 데이터베이스에는 실험 행과 측정값 행을 분리합니다. 작업 결과의 재분석 실패는 성공한 계산 상태를 실패로 바꾸지 않습니다.

## 재료와 측정값

재료 ID는 정규화된 SMILES와 명시한 사슬 길이·서열·입체규칙성·조성 등의 JSON으로부터 계산한 SHA256입니다. 같은 반복단위라도 명시한 사슬 길이나 준비 조건이 다르면 보수적으로 구분합니다. 자동으로 화학적 동등성을 증명하지 않습니다. 일반 CG 비드는 특정 화학종에 매핑되지 않으므로 실제 실험 물성과 직접 연결할 수 없습니다.

측정값에는 재료 또는 색인된 작업 ID, 물성, 수치, 단위, 측정법, 조건, 출처, 출처 유형, 검토 여부가 필요합니다. Tg는 K, 탄성률·인장강도는 MPa, 결합 친화도는 해리상수 Kd(nM), RMSD는 Å로 정규화하며 원래 값·단위도 보존합니다. 기본 검토 상태는 false입니다. 검토 전 값과 demo/simulation 값은 실험 대리 모델 학습에서 제외합니다.

Hansen 용해도 파라미터 `hsp_delta_d`·`hsp_delta_p`·`hsp_delta_h`·`hsp_radius`는 MPa½로 정규화하며 (cal/cm³)½ 입력은 2.0455배로 환산합니다. **빠른 예측 · 상용성** 화면의 구 피팅 결과를 초안으로 넘길 수 있습니다.

CSV 열 예시는 아래와 같습니다. JSON 값에 쉼표가 포함되면 표준 CSV 따옴표 규칙으로 감싸야 합니다. 업로드는 미리보기 이후 별도 저장 단계가 있으며 일부 행이 유효하지 않으면 전체 저장을 취소합니다.

```text
repeat_smiles,property,value,unit,method,source,origin
[*]CC[*],tg,80,C,DSC,사용자 실험 노트 17,experimental
```

이 예시 수치는 형식을 설명하기 위한 값이며 실제 고분자의 물성이 아닙니다. `material_json`과 `conditions_json` 열로 재료의 추가 구분 정보와 측정 조건을 입력할 수 있습니다. CSV의 검토 상태는 업로드만으로 승인되지 않습니다.

## 궤적 피처

- Rg는 토폴로지로 구분한 각 사슬의 질량 중심 기준 회전반경입니다. 서로 떨어진 여러 사슬을 하나의 사슬로 처리하지 않습니다.
- 말단 거리·접선 상관·이면각 엔트로피는 검증 가능한 선형 주사슬이 있을 때만 계산합니다. 분지·고리 구조에서 임의로 말단을 추측하지 않습니다.
- 이면각 값은 고정 구간 히스토그램의 이산 엔트로피이며 열역학적 엔트로피가 아닙니다. 접선 상관도 지속 길이의 직접 추정값이 아닙니다.
- 쌍극자 변동은 전하가 명시된 중성 사슬의 실제 동역학 프레임에 한정합니다. 구조 생성·최소화의 두 장면을 MD 표본으로 간주하지 않습니다.
- RadonPy 벌크 셀 작업은 RadonPy가 샘플링 로그에서 계산한 `bulk_density`(g/cm³), `bulk_modulus`(GPa), `heat_capacity_cp`(J/(kg·K)), `isothermal_compressibility`(1/GPa), `volume_expansion`(1/K), 사슬 `rg_mean`(Å)을 피처로 색인합니다. 각 값의 분석법에 프로토콜 길이 배율과 힘장·전하법이 들어가며, RadonPy 수렴 기준 충족 여부를 함께 저장합니다. 밀도 시계열에는 PyMBAR 정상성 후보를 기록합니다. 실험 밀도는 측정값 `density`(g/cm³)로 입력해 비교할 수 있습니다. 변동 기반 물성은 긴 샘플링이 필요하며 짧은 계산에서는 부호·크기가 비물리적일 수 있습니다.
- PyMBAR의 탐지값은 특정 관측량에 대한 통계적 절단점 후보입니다. 물리적 평형을 증명하지 않으며 항상 `equilibrated: false`를 유지합니다.
- Martini 3 혼합계 MD 작업은 `gmx trjconv -pbc mol`로 분자를 온전하게 만든 생산 구간 프레임에서 단백질 BB 비드 RMSD(최소화 구조에 최적 중첩), 단백질·고분자 사슬별 비가중 회전반경, 단백질 비드로부터 지정 거리(기본 0.6 nm, 주기 경계 최소 영상) 안의 고분자 비드 수, 최소 거리, NPT 밀도를 계산해 `protein_rmsd`, `contact_count`, `protein_rg_mean`, `polymer_rg_mean`, `density_mean` 피처로 색인합니다. 접촉 수는 기준 거리와 Martini 비드 해상도에 따라 달라지는 값입니다. 밀도는 용매화 계 전체의 값이며 고분자 재료 밀도가 아닙니다.
- 조대화 비드에는 수소가 없어 수소결합 수는 계산하지 않습니다. SASA·RDF와 전원자 혼합계 궤적 분석은 현재 자동 분석 대상이 아닙니다. 필요한 선택·기준 구조·절단 거리·정규화 조건이 없으면 누락 사유를 기록합니다. 관련 측정값은 출처·방법·조건과 함께 별도로 입력할 수 있습니다.

## 실험 곡선과 PDF

DSC는 사용자가 고른 두 선형 기준선 사이에서 열 흐름의 중간 교차 온도를 구합니다. 가열 속도·이력·흡열 피크의 영향을 검토한 뒤 측정값으로 저장해야 합니다. 인장 곡선은 사용자가 지정한 변형률/응력 단위와 선형 구간의 회귀 기울기를 사용합니다. 기기 컴플라이언스·시편 치수·toe 보정은 자동 적용하지 않습니다.

TGA는 사용자가 지정한 기준 온도의 질량을 100%로 두고, 그 이후 처음으로 지정 감소율(예: 5%)에 도달하는 온도를 인접한 두 점의 선형 보간으로 구해 `decomposition_temperature`(K) 초안을 만듭니다. 온도·질량 단위, 분위기, 가열 속도를 명시해야 합니다. 첫 측정점 대신 수분 제거 이후 온도를 기준으로 선택할 수 있습니다. 음수 질량은 공시료·부력 보정이 되지 않은 곡선으로 보고 거부합니다. 접선 외삽 onset, 공시료·부력 보정, DTG 피크는 계산하지 않습니다.

GPC는 좁은 분포 표준의 `log10 M`을 용출 시간 또는 부피의 1~3차 다항식으로 맞춘 일반 보정(conventional calibration)을 사용합니다. 표준은 차수+2개 이상이어야 하고 분자량이 용출 순서대로 감소해야 합니다. 적분 구간은 보정 범위 안에 있어야 하며 그 구간에서 보정식이 단조 감소하지 않으면 거부합니다. 피크 앞뒤 두 기준선 창을 지나는 직선을 빼고, 구간 폭을 고려한 농도 검출기 신호를 질량 분율로 사용해 Mn = 1/Σ(wᵢ/Mᵢ), Mw = Σ wᵢMᵢ, Đ = Mw/Mn 초안을 만듭니다. 보정 후 음수 면적이 2%를 넘으면 기준선 재설정을 요구하고 그 이하는 0으로 잘라 비율을 기록합니다. 적분 경계 신호가 피크의 5%를 넘으면 분포가 잘렸을 수 있다고 경고합니다. 값은 보정 표준(예: polystyrene) 환산 상대 분자량이며 universal calibration, Mark–Houwink 변환, 광산란 절대 분자량, 밴드 퍼짐·유속 보정은 적용하지 않습니다. RI 외 검출기는 신호가 질량 농도에 비례한다는 가정을 경고합니다.

TGA·GPC 초안의 `conditions`에는 같은 프로토콜의 반복 측정끼리 비교할 수 있는 조건(감소율·분위기·가열 속도·기준 온도, 보정 표준·차수·검출기·x 단위·용리액)만 넣습니다. 시료마다 달라지는 기준선·적분 구간, 보정 적합 결과와 표준 데이터 해시, 보간에 쓴 두 점은 `analysis`에 보관합니다. 화면에서 초안을 측정값 양식에 넣고 값·물성·단위를 바꾸지 않고 저장하면 `analysis`도 함께 저장됩니다. 분석 조건을 비워 두면 TGA/GPC 곡선을 물성값 없이 미리보기로만 확인합니다.

PDF는 최대 10 MB·100페이지에서 텍스트를 추출하고 원본 파일·SHA256·페이지 번호를 보관합니다. 표와 그림의 의미를 추론하거나 자동 측정값을 등록하지 않습니다. 스캔 문서의 OCR, 외부 LLM 호출, 유료 문헌 데이터 수집은 수행하지 않습니다.

## 일관된 백업

프로세스/스레드 잠금으로 DuckDB 접근을 직렬화합니다. 내보내기는 하나의 읽기 트랜잭션에서 `experiments_master.parquet`와 `measurements.parquet`를 만들고, 개수·해시를 가진 `metadata.json`과 함께 새 폴더에 게시합니다. 동일 파일을 변경하는 실시간 클라우드 DB 동기화 방식이 아닙니다.

스냅샷 ZIP에는 두 테이블과 메타데이터가 들어갑니다. 큰 원본 궤적·로그·PDF는 별도로 보관되므로 계산별 ZIP도 함께 백업해야 전체 원본을 복원할 수 있습니다. 이미 설정된 Drive/rclone 동기화 폴더에 스냅샷을 복사할 수 있지만 원격 업로드 완료 여부는 그 동기화 프로그램에서 확인해야 합니다.
